# 前后端通讯

## 文档说明

本文档描述 DataTrace 系统的前后端通讯机制，基于 HTTP REST + SSE。

**文档版本**: v2.0
**最后更新**: 2026-07
**通讯框架**: HTTP REST（请求-响应）+ SSE（事件推送）

---

## 通讯架构

```
┌─────────────────────────────────────────────────────────────┐
│                    前端 (Vue 3 + TypeScript)                 │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  API 层 (api/)                                        │  │
│  │  - axios/fetch HTTP 请求                              │  │
│  │  - EventSource SSE 客户端                             │  │
│  │  - Pinia Store 状态管理                               │  │
│  └──────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
                    ↕ HTTP / SSE
┌─────────────────────────────────────────────────────────────┐
│                    后端 (Go + Gin)                           │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  API Layer (api/)                                     │  │
│  │  - Gin Handler 处理 REST 请求                         │  │
│  │  - 统一响应格式 { code, message, data }               │  │
│  └──────────────────────────────────────────────────────┘  │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  SSE Hub                                              │  │
│  │  - 统一 SSE 端点 /api/v1/sse?topics=...              │  │
│  │  - Topic 订阅过滤                                     │  │
│  │  - 快照缓存（新连接立即推送最新状态）                  │  │
│  └──────────────────────────────────────────────────────┘  │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  EventBus（进程内事件总线）                            │  │
│  │  - 业务层发布事件                                     │  │
│  │  - SSEHub 订阅并推送给前端                            │  │
│  └──────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

## 1. REST 请求（请求-响应模式）

**用途**：前端调用后端 CRUD 操作、任务控制等

**流程**：
```
前端 fetch/axios → Gin Handler → Service → 返回 JSON 响应
```

**前端示例**：
```typescript
// src/api/datasource.ts
export const datasourceApi = {
  async list(): Promise<DataSource[]> {
    const res = await fetch('/api/v1/datasources')
    const json = await res.json()
    return json.data
  },

  async create(data: CreateDataSourceRequest): Promise<DataSource> {
    const res = await fetch('/api/v1/datasources', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(data),
    })
    const json = await res.json()
    return json.data
  },

  async testConnection(id: string): Promise<TestResult> {
    const res = await fetch(`/api/v1/datasources/${id}/test`, { method: 'POST' })
    return (await res.json()).data
  },
}
```

**后端示例**：
```go
// api/datasource_api.go
func (api *DataSourceAPI) List(c *gin.Context) {
    datasources, err := api.svc.List()
    if err != nil {
        common.Error(c, 500, err.Error())
        return
    }
    common.Success(c, datasources)
}
```

## 2. SSE 事件推送（事件驱动模式）

**用途**：后端主动推送实时数据到前端（进度、日志、状态变更等）

**流程**：
```
业务层 EventBus.Publish() → SSEHub 桥接 → SSE 推送 → 前端 EventSource 监听
```

### SSE 端点

`GET /api/v1/sse?topics=task:{id}:detail,task:{id}:progress,task:{id}:logs`

### 前端连接示例

```typescript
// stores/task.ts (Pinia)
export const useTaskStore = defineStore('task', () => {
    const eventSource = ref<EventSource | null>(null)
    const taskDetail = ref<TaskDetail | null>(null)
    const progress = ref<ProgressData | null>(null)
    const logs = ref<LogEntry[]>([])

    function connectSSE(taskId: string) {
        const topics = [
            `task:${taskId}:detail`,
            `task:${taskId}:progress`,
            `task:${taskId}:logs`,
            `task:${taskId}:table_status`,
            `task:${taskId}:step_status`,
        ].join(',')

        const es = new EventSource(`/api/v1/sse?topics=${topics}`)

        es.addEventListener('task_detail', (e) => {
            taskDetail.value = JSON.parse(e.data)
        })

        es.addEventListener('progress', (e) => {
            progress.value = JSON.parse(e.data)
        })

        es.addEventListener('log', (e) => {
            logs.value.push(JSON.parse(e.data))
            // 限制最大 1000 条
            if (logs.value.length > 1000) logs.value.shift()
        })

        eventSource.value = es
    }

    function disconnectSSE() {
        eventSource.value?.close()
        eventSource.value = null
    }

    return { connectSSE, disconnectSSE, taskDetail, progress, logs }
})
```

### 后端推送链路

```
SyncEngine 同步进度变更
  → EventBus.Publish("task.progress", { task_id, progress })
    → SSEHub 桥接函数：
        topic = "task:{task_id}:progress"
        SSEHub.PublishJSON(topic, "progress", data)
          → 匹配该 topic 的 SSE 客户端收到事件
```

### EventBus → SSEHub 桥接注册

```go
// app/container.go - registerBridges()

// 任务进度 → SSE
eventBus.Subscribe("task.progress", func(data interface{}) {
    topic := fmt.Sprintf("task:%s:progress", data["task_id"])
    sseHub.PublishJSON(topic, "progress", data["progress"])

// 任务详情 → SSE（自动附加 target_conns）

    sseHub.PublishJSON(topic, "task_detail", data)

// 任务日志 → SSE + 文件持久化
```

## 3. SSE 连接生命周期

```
页面进入（onMounted / onActivated）
  │
  ├── 创建 EventSource 连接
  ├── 注册事件监听
  └── 接收实时数据 → 更新 Pinia state
        │
页面离开（onUnmounted / onDeactivated）
  │
  ├── 关闭 EventSource 连接
  └── 清除本地缓存状态
```

**关键规则**：
- SSE 连接跟随页面生命周期，进入页面建立，离开页面断开
- 新连接建立时，SSEHub 立即推送缓存快照（最新状态）
- 所有数据变更通过 SSE 推送，**禁止轮询/ticker 兜底**

## 5. 错误处理

### 后端

```go
// Service 层返回 error
func (svc *DataSourceService) Delete(id string) error {
    // 检查是否被任务引用
    if svc.isReferenced(id) {
        return fmt.Errorf("该数据源正被任务引用，无法删除")
    }
    return svc.db.Delete(&models.DataSource{}, "id = ?", id).Error
}

// API 层转换为 HTTP 响应
func (api *DataSourceAPI) Delete(c *gin.Context) {
    id := c.Param("id")
    if err := api.svc.Delete(id); err != nil {
        common.Error(c, 400, err.Error())
        return
    }
    common.Success(c, nil)
}
```

### 前端

```typescript
try {
  await datasourceApi.delete(id)
  showMessage.success('删除成功')
} catch (error) {
  showMessage.error(error.message)
}
```

### 常见错误

| 错误信息 | 说明 |
|---|---|
| "该凭据正被 N 个数据源使用" | 删除保护 |
| "该数据源正被 N 个任务使用" | 删除保护 |
| "任务正在运行中，无法删除" | 运行中禁止删除 |
| "增量同步中不允许修改已同步的表" | 配置约束 |

## 🔄 通讯方式

### 1. Commands (请求-响应模式)

**用途**: 前端调用后端功能,等待返回结果

**流程**:
```
前端 invoke(command, args) → 后端执行 → 返回结果 → 前端接收
```

**前端示例**:
```typescript
// src/api/datasource.ts
import { invoke } from '@tauri-apps/api/core';

export const datasourceApi = {
  async list(): Promise<DataSource[]> {
    return await invoke('list_data_sources');
  },
  
  async create(data: CreateDataSourceRequest): Promise<DataSource> {
    return await invoke('create_data_source', { data });
  },
  
  async testConnection(id: string): Promise<void> {
    return await invoke('test_data_source_connection', { id });
  },
};
```

**后端示例**:
```rust
// src-tauri/src/commands.rs
#[tauri::command]
pub async fn list_data_sources(
    state: State<'_, AppState>,
) -> Result<Vec<DataSource>, String> {
    state.data_source_manager
        .list_data_sources()
        .await
        .map_err(|e| e.to_string())
}

#[tauri::command]
pub async fn create_data_source(
    data: CreateDataSourceRequest,
    state: State<'_, AppState>,
) -> Result<DataSource, String> {
    state.data_source_manager
        .create_data_source(data)
        .await
        .map_err(|e| e.to_string())
}
```

### 2. Events (事件推送模式)

**用途**: 后端主动推送数据到前端,用于实时更新

**流程**:
```
后端 emit(event, payload) → 前端监听器接收 → 更新 UI
```

**后端推送示例**:
```rust
// src-tauri/src/progress.rs
impl ProgressMonitor {
    fn emit_progress(&self, task_id: &str) {
        if let Some(progress) = self.get_task_progress(task_id) {
            let _ = self.app_handle.emit("task-progress", progress);
        }
    }
    
    pub fn add_log(&self, task_id: &str, level: LogLevel, category: LogCategory, message: String) {
        let log_entry = LogEntry {
            timestamp: chrono::Utc::now().timestamp_millis(),
            level,
            category,
            message,
        };
        
        // 推送日志事件
        let _ = self.app_handle.emit("task-log", TaskLogEvent {
            task_id: task_id.to_string(),
            log: log_entry,
        });
    }
}
```

**前端监听示例**:
```typescript
// src/views/TaskMonitor/composables/useTaskMonitor.ts
import { listen } from '@tauri-apps/api/event';

export function useTaskMonitor(taskId: string) {
  const progress = ref<TaskProgress | null>(null);
  const logs = ref<LogEntry[]>([]);
  let unlistenProgress: (() => void) | null = null;
  let unlistenLog: (() => void) | null = null;
  
  async function startListening() {
    // 监听进度更新
    unlistenProgress = await listen<TaskProgress>('task-progress', (event) => {
      if (event.payload.taskId === taskId) {
        progress.value = event.payload;
      }
    });
    
    // 监听日志推送
    unlistenLog = await listen<TaskLogEvent>('task-log', (event) => {
      if (event.payload.taskId === taskId) {
        logs.value.push(event.payload.log);
      }
    });
  }
  
  function stopListening() {
    if (unlistenProgress) {
      unlistenProgress();
      unlistenProgress = null;
    }
    if (unlistenLog) {
      unlistenLog();
      unlistenLog = null;
    }
  }
  
  onMounted(() => {
    startListening();
  });
  
  onUnmounted(() => {
    stopListening();
  });
  
  return { progress, logs };
}
```

### 3. State (共享状态)

**用途**: 在后端维护全局状态,供多个 Command 访问

**后端示例**:
```rust
// src-tauri/src/lib.rs
pub struct AppState {
    pub data_source_manager: Arc<DataSourceManager>,
    pub sync_engine: Arc<SyncEngine>,
    pub progress_monitor: Arc<ProgressMonitor>,
    pub error_logger: Arc<ErrorLogger>,
}

#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    tauri::Builder::default()
        .setup(|app| {
            // 初始化状态
            let storage = Arc::new(Storage::new(&db_path).await?);
            let crypto = Arc::new(Crypto::new()?);
            let data_source_manager = Arc::new(DataSourceManager::new(storage.clone(), crypto));
            let progress_monitor = Arc::new(ProgressMonitor::new(app.handle().clone()));
            let error_logger = Arc::new(ErrorLogger::new());
            let sync_engine = Arc::new(SyncEngine::new(
                data_source_manager.clone(),
                progress_monitor.clone(),
                error_logger.clone(),
            ));
            
            // 注册状态
            app.manage(AppState {
                data_source_manager,
                sync_engine,
                progress_monitor,
                error_logger,
            });
            
            Ok(())
        })
        .invoke_handler(tauri::generate_handler![
            list_data_sources,
            create_data_source,
            start_sync_task,
            // ... 其他 commands
        ])
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

**访问状态**:
```rust
#[tauri::command]
pub async fn some_command(
    state: State<'_, AppState>,

    state.sync_engine.do_something_else().await?;

}
```
