# 数据交换框架设计

## 文档说明

本文档描述 DataTrace 的数据交换框架，包括全量同步和增量同步的完整流程。

**文档版本**: v2.0
**最后更新**: 2026-07

---

## 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                    TaskControlService                        │
│  StartFullSyncTask() / StartIncrementalTask()                │
└─────────────────────────────────────────────────────────────┘
        ↓ 全量                              ↓ 增量
┌───────────────────────┐   ┌────────────────────────────────┐
│   SyncEngine          │   │   IncrementalSync              │
│   ├── MySQLReader     │   │   ├── BinlogListener           │
│   ├── MySQLWriter     │   │   ├── BinlogQueue (扇出)       │
│   ├── ForeignKey      │   │   ├── IncrementalConsumer × N  │
│   │   Analyzer        │   │   └── IncrementalStatsService  │
│   └── AdaptiveConfig  │   │                                │
│       Calculator      │   │   FullSyncStarter (先全量后增量) │
└───────────────────────┘   └────────────────────────────────┘
        ↓ 读写                            ↓ 消费
┌───────────────────────────────────────────────────────────────┐
│  源 MySQL ←→ Binlog ←→ 目标 MySQL × N                         │
└───────────────────────────────────────────────────────────────┘
```

## 全量同步

### 组件

| 组件 | 文件 | 职责 |
|---|---|---|
| SyncEngine | `sync_engine.go` | 同步编排，并发控制 |
| MySQLReader | `mysql_reader.go` | 分批读取源数据 |
| MySQLWriter | `mysql_writer.go` | 批量写入目标库 |
| ForeignKeyAnalyzer | `foreign_key_analyzer.go` | 外键拓扑排序 |
| AdaptiveConfigCalculator | `adaptive_config_calculator.go` | 自适应批次大小 |
| SyncInit | `sync_init.go` | 目标库初始化（建库建表） |
| FullSyncStarter | `task_full_sync_starter.go` | 全量→增量编排 |

### 流程

```
TaskControlService.StartFullSyncTask()
  │
  ├── 1. TaskLogSvc.ClearLogs()              → 清空旧日志
  ├── 2. TableStatusSvc.ClearTaskTables()    → 重置表状态
  ├── 3. TableStatusSvc.InitSteps()          → 初始化步骤状态
  ├── 4. ProgressMgr.InitProgress()          → 初始化进度
  │
  ├── 5. ForeignKeyAnalyzer.Analyze()        → 拓扑排序（外键依赖）
  │       返回有序表列表
  │
  ├── 6. SyncInit.InitTargetDatabases()      → 创建目标库
  ├── 7. SyncInit.InitTargetTables()         → 创建目标表（DDL）
  │
  └── 8. SyncEngine.SyncTable() × N 并发
        │
        ├── MySQLReader.GetColumns()          → 获取列信息
        ├── MySQLReader.GetRowCount()         → 获取总行数
        ├── ProgressMgr.StartTable()          → 标记表开始
        │
        └── 循环分批读写:
              ├── MySQLReader.ReadBatch(offset, limit)
              ├── MySQLWriter.BatchInsert(columns, rows)
              ├── ProgressMgr.UpdateProgress()
              └── EventBus.Publish("task.progress")
```

### MySQLReader

```go
type MySQLReader struct {
    db *sql.DB
}

// 分批读取，ORDER BY 保证顺序稳定
func (r *MySQLReader) ReadBatch(ctx context.Context, database, table string,
    columns []string, offset, limit int) ([][]interface{}, error)

// 获取列信息
func (r *MySQLReader) GetColumns(ctx context.Context, database, table string) ([]ColumnInfo, error)

// 获取行数
func (r *MySQLReader) GetRowCount(ctx context.Context, database, table string) (int64, error)
```

### MySQLWriter

```go
type MySQLWriter struct {
    db *sql.DB
}

// 批量插入（多值 INSERT，遵守 65535 占位符限制）
func (w *MySQLWriter) BatchInsert(ctx context.Context, database, table string,
    columns []string, rows [][]interface{}) error

// 建库
func (w *MySQLWriter) CreateDatabase(ctx context.Context, database string) error

// 建表（使用源表 DDL）
func (w *MySQLWriter) CreateTable(ctx context.Context, targetDB, targetTable, ddl string) error

// 清空表
func (w *MySQLWriter) TruncateTable(ctx context.Context, database, table string) error
```

### 并发控制

- 多表并发：按拓扑排序顺序，同层级表并发同步
- 单表串行：分批读写，每批默认 1000 行
- 自适应批次：根据列数和 MySQL 限制动态计算
- 单表超时：可配置，默认 30 分钟

| ConsumerEventHandler | `incremental_consumer_event_handler.go` | 事件处理逻辑 |
| ConsumerMapper | `incremental_consumer_mapper.go` | 源→目标映射 |
| IncrementalStatsService | `incremental_stats_service.go` | 统计服务 |
| IncrementalSyncHelpers | `incremental_sync_helpers.go` | 辅助函数 |

### 流程

```
TaskControlService.StartIncrementalTask()
  │
  └── IncrementalSync.Start(ctx, taskID, config, sourceDSN, targets)
        │
        ├── 1. 检查 binlog_format=ROW
        ├── 2. 捕获快照点（File+Position / GTID）
        ├── 3. 创建 BinlogQueue × len(targets)（扇出队列）
        ├── 4. 创建 IncrementalConsumer × len(targets)
        ├── 5. FullSyncStarter.Start()
        │       ├── 先执行全量同步（SyncEngine）
        │       └── 全量完成后启动 BinlogListener
        ├── 6. Consumer.Start() × N（异步消费）
        │       ├── 从 Queue 拉取事件
        │       ├── Mapper 映射源→目标
        │       ├── EventHandler 处理 INSERT/UPDATE/DELETE
        │       └── MySQLWriter 写入目标库
        └── 7. BinlogListener.Start()
                ├── 从快照点开始监听
                ├── 过滤表（filterTables）
                └── 事件分发到各 Queue（扇出）
```

### BinlogListener

- 基于 `go-mysql-org/go-mysql/canal` 实现
- 支持表过滤（动态添加/移除）
- 扇出模式：一个 Listener → N 个 Queue → N 个 Consumer
- 支持 Position 和 GTID 两种断点

### BinlogQueue

```go
type BinlogQueue interface {
    Push(event *BinlogEvent) error
    Pull() (*BinlogEvent, error)
    Ack(offset int64) error
    Len() int
}
```

两种实现：
- **MemoryQueue**：进程内 channel，重启丢失
- **RedisQueue**：Redis List，持久化，支持断点续传

### IncrementalConsumer

```
Queue.Pull() → BinlogEvent
  → Mapper.Map(sourceDB, sourceTable) → (targetDB, targetTable)
  → EventHandler.Handle(event)
    → INSERT: BatchInsert
    → UPDATE: 生成 SET + WHERE 语句
    → DELETE: 生成 DELETE 语句
  → MySQLWriter 执行
  → Queue.Ack(offset)
  → StatsSvc.UpdateStats()
```

## 多目标同步

任务支持多个目标数据源：

```
源 MySQL ──→ BinlogListener
                ├── Queue_1 → Consumer_1 → 目标 MySQL_1
                ├── Queue_2 → Consumer_2 → 目标 MySQL_2
                └── Queue_N → Consumer_N → 目标 MySQL_N
```

- 每个目标有独立的 Queue 和 Consumer
- 全量同步时每个目标独立并发
- 增量同步时 Binlog 事件扇出到所有 Queue

# 数据交换框架设计 (Reader-Transformer-Writer)

## 📋 文档说明

本文档定义了 DataTrac 的核心底座——数据交换框架。通过抽象 Reader（读）、Transformer（转）、Writer（写）三个核心组件，实现跨异构数据源的自由传输。

**文档版本**: v1.0  
**最后更新**: 2026-01-30  
**状态**: 初稿完成

---

## 🎯 设计理念

为了实现“完美且强大的底座”，框架遵循以下原则：
1. **插件化 (Pluggable)**: 新增数据源只需实现对应的 Reader 或 Writer。
2. **正交性 (Orthogonality)**: 读逻辑与写逻辑完全解耦，通过标准中间格式交换数据。
3. **流水线 (Pipeline)**: 数据以流式 Batch 的方式在组件间传递，支持背压和并发。

---

## 🏗️ 核心抽象

### 1. 标准数据记录 (DataRecord)

所有数据源在传输过程中都必须转换为统一的中间格式。

```rust
pub enum FieldValue {
    Null,
    Boolean(bool),
    Integer(i64),
    Float(f64),
    Text(String),
    DateTime(chrono::DateTime<chrono::Utc>),
    Json(serde_json::Value), // 处理复杂对象或数组
    Binary(Vec<u8>),
}

pub struct DataRecord {
    pub fields: HashMap<String, FieldValue>,
    pub metadata: HashMap<String, String>, // 存储如主键 ID、版本号等辅助信息
}
```

### 2. 源读取器 (SourceReader)

定义如何从源头提取数据。

```rust
#[async_trait]
pub trait SourceReader: Send + Sync {
    /// 初始化连接和准备工作
    async fn open(&mut self) -> Result<()>;
    
    /// 获取总记录数（用于进度条）
    async fn get_total_count(&self) -> Result<u64>;
    
    /// 读取一个批次的数据
    async fn read_batch(&mut self, batch_size: usize) -> Result<Vec<DataRecord>>;
    
    /// 检查是否还有更多数据
    fn has_next(&self) -> bool;
    
    /// 释放资源
    async fn close(&mut self) -> Result<()>;
}
```

### 3. 目标写入器 (TargetWriter)

定义如何将数据写入目标。

```rust
#[async_trait]
pub trait TargetWriter: Send + Sync {
    /// 初始化连接
    async fn open(&mut self) -> Result<()>;
    
    /// 根据源元数据准备目标表结构/索引 Mapping
    async fn prepare_target(&self, schema_info: &SchemaInfo) -> Result<()>;
    
    /// 写入一个批次的数据
    async fn write_batch(&mut self, batch: Vec<DataRecord>) -> Result<()>;
    
    /// 提交事务或刷新缓冲区
    async fn commit(&mut self) -> Result<()>;
    
    /// 释放资源
    async fn close(&mut self) -> Result<()>;
}
```

### 4. 转换器 (Transformer)

在读写之间处理数据。

```rust
pub trait Transformer: Send + Sync {
    /// 转换单条记录（字段改名、类型转换、脱敏等）
    fn transform(&self, record: DataRecord) -> Result<DataRecord>;
}
```

## 🔄 同步管道 (SyncPipeline)

管道是底座的运行实体，它负责组装并运行上述组件。

### 管道结构
```rust
pub struct SyncPipeline {
    reader: Box<dyn SourceReader>,
    writer: Box<dyn TargetWriter>,
    transformers: Vec<Box<dyn Transformer>>,
    progress_monitor: Arc<ProgressMonitor>,
}
```

### 运行逻辑
```
1. pipeline.open() -> Reader & Writer 初始化
2. pipeline.prepare() -> Writer 根据 Reader 提供的 Schema 创建目标环境
3. while reader.has_next():
   a. batch = reader.read_batch(size)
   b. for t in transformers: batch = t.transform_all(batch)
   c. writer.write_batch(batch)
   d. progress_monitor.update(batch.len())
4. pipeline.close() -> 释放所有资源
```

## 🚀 扩展性示例

### 实现 MySQL → MySQL
- 实现 `MySqlReader`: 执行 `SELECT`，将 `sqlx::Row` 转为 `DataRecord`。
- 实现 `MySqlWriter`: 执行 `INSERT INTO ...`。
- 复用 `DefaultTransformer`: 处理基本的名称映射。

### 实现 MySQL → MongoDB
- **复用** `MySqlReader`。
- 实现 `MongoWriter`: 将 `DataRecord` 转为 `BSON` 写入。
- **无需改动底座代码**。

### 实现 MongoDB → ES
- 实现 `MongoReader`。
- 实现 `ElasticWriter` (或复用已有)。
- **即插即用**。
