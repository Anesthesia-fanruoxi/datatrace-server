## 依赖注入容器

### 设计原则

- **禁止**全局变量（`var DB *gorm.DB`）
- **禁止** `sync.Once` 单例
- **统一**通过 `AppContainer` 管理所有 Service 生命周期

### AppContainer 结构

```go
type AppContainer struct {
    Config *config.Config

    // Infrastructure
    DB         *gorm.DB
    Redis      *redis.Client
    Cache      services.CacheStore       // 接口：MemoryCache 或 RedisCache
    EventBus   *services.EventBus
    SSEHub     *services.SSEHub
    Crypto     *utils.CryptoService

    // Business Services
    CredentialSvc   *services.CredentialService
    DataSourceSvc   *services.DataSourceService
    TaskSvc         *services.TaskService

    // Sync Engine
    ProgressMgr     *services.TaskProgressManager
    ExecMgr         *services.TaskExecutionManager
    SyncEngine      *services.SyncEngine
    FullSyncStarter *services.FullSyncStarter

    // Incremental Sync
    IncrStatsSvc    *services.IncrementalStatsService
    IncrSync        *services.IncrementalSync
    TaskControlSvc  *services.TaskControlService

    // Auxiliary Services
    HealthCheckSvc  *services.HealthCheckService
    TaskLogSvc      *services.TaskLogService
    TableStatusSvc  *services.TaskTableStatusService
}
```

### 初始化流程

```
main.go
  ├── 1. config.LoadConfig("config.yaml")
  ├── 1.1 common.SetupLogger(cfg.Logging)       → 日志系统初始化
  ├── 2. database.InitDB(cfg)                    → *gorm.DB
  ├── 3. database.InitRedis(cfg)                 → *redis.Client（可选）
  ├── 4. app.NewAppContainer(cfg, db, redisClient)
  │       ├── NewCacheStore(redis)                → Memory 或 Redis 降级
  │       ├── NewEventBus()
  │       ├── NewSSEHub()
  │       ├── AutoMigrate(Credential/DataSource/SyncTask/TaskTargetSource)
  │       ├── initServices()                     → 按顺序创建所有 Service
  │       └── registerBridges()                   → EventBus → SSEHub 桥接
  ├── 5. app.Start()
  │       └── HealthCheckSvc.Start(30s)           → 定时健康检查
  ├── 6. routers.SetupRouter(app)                 → Gin 路由
  └── 7. r.Run(addr)                              → HTTP 服务器
```

## 任务日志生命周期

```
EventBus.Publish("task.log")
  ├── TaskLogSvc.AppendLog(taskID, category, message)  → 写入文件
  └── SSEHub.Publish("task:{id}:logs", "log", data)     → 实时推送
```

日志文件路径：`logs/tasks/{taskID}.log`，格式：`时间\t级别\t分类\t内容`

## 安全性

- 数据源密码使用 AES-256-GCM 加密存储
- 加密密钥配置在 `config.yaml` 的 `security.encryption_key`（32 字节）
- 凭据密码同样加密存储

---

## 错误处理

- Service 层返回 `error`，不直接处理 HTTP 响应
- API 层统一响应格式：`{ "code": int, "message": string, "data": any }`
- 所有 goroutine 有 `recover` 保护（Gin Recovery 中间件）

## 📦 核心模块

### 1. API 层 (Commands)

**文件**: `commands.rs`

**职责**:
- 暴露 Tauri Commands 给前端
- 参数验证和类型转换
- 错误处理和转换
- 调用服务层

**示例**:
```rust
#[tauri::command]
pub async fn list_data_sources(
    state: State<'_, AppState>,
) -> Result<Vec<DataSource>, String> {
    state.data_source_manager
        .list_data_sources()
        .await
        .map_err(|e| e.to_string())
}

#[tauri::command]
pub async fn start_sync_task(
    task_id: String,
    state: State<'_, AppState>,
) -> Result<(), String> {
    state.sync_engine
        .start_sync_by_id(&task_id)
        .await
        .map_err(|e| e.to_string())
}
```

**命名规范**:
- 使用 snake_case 命名函数
- 使用 `#[serde(rename_all = "camelCase")]` 转换为前端的 camelCase

## 🔄 核心工作流程

### 任务启动流程

```
1. 前端调用 start_sync_task(task_id)
   ↓
2. Commands 层接收请求
   ↓
3. SyncEngine.start_sync_by_id(task_id)
   ├─ 更新任务状态为 Running
   ├─ TaskLoader.load_and_parse_task(task_id)
   │   └─ 从数据库加载任务配置
   ├─ TaskLoader.init_task_units(task_id)
   │   ├─ 从配置表读取单元列表
   │   ├─ 创建/更新运行记录表
   │   └─ 支持断点续传
   └─ SyncEngine.start_sync(config)
       ↓
4. 根据同步方向调用对应实现
   ├─ sync_mysql_to_es
   ├─ sync_es_to_mysql
   ├─ sync_mysql_to_mysql
   └─ sync_es_to_es
       ↓
5. TaskManager.execute_auto_mode()
   ├─ 从数据库加载任务单元
   ├─ 过滤出未完成的单元
   ├─ 使用 Semaphore 控制并发
   └─ 并发执行所有未完成单元
       ↓
6. 为每个单元执行同步
   ├─ 更新状态为 Running
   ├─ 读取源数据
   ├─ 转换数据格式
   ├─ 写入目标数据源
   ├─ 更新进度到数据库
   ├─ 推送进度到前端
   └─ 标记完成/失败
       ↓
7. 所有单元完成
   ├─ 更新任务状态为 Completed/Failed
   └─ 推送最终状态到前端
```

## 🔧 并发控制

### Tokio Semaphore

使用 Tokio 的 Semaphore 控制并发数:

```rust
pub async fn execute_auto_mode<F, Fut>(
    &self,
    task_id: &str,
    concurrency: usize,
    progress_monitor: Arc<ProgressMonitor>,
    process_fn: F,
) -> Result<usize>
where
    F: Fn(String, String) -> Fut + Send + Sync + 'static,
    Fut: std::future::Future<Output = Result<()>> + Send,
{
    // 创建信号量
    let semaphore = Arc::new(Semaphore::new(concurrency));
    let mut tasks = Vec::new();
    
    for unit in pending_units {
        // 获取许可
        let permit = semaphore.clone().acquire_owned().await?;
        
        // 启动异步任务
        let task = tokio::spawn(async move {
            // 执行同步
            let result = process_fn(unit_id, unit_name).await;
            
            // 释放许可
            drop(permit);
        });
        
        tasks.push(task);
    }
    
    // 等待所有任务完成
    for task in tasks {
        let _ = task.await;
    }
    
    Ok(success_count)
}
```
