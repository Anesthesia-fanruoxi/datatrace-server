## 🔐 加密服务 (CryptoService)

### 功能说明

加密服务负责保护敏感信息（如数据源密码），使用 AES-256-GCM 加密算法。

### 核心特性

- **加密算法**: AES-256-GCM（高强度对称加密）
- **密钥管理**: 从配置文件或环境变量读取
- **Nonce**: 每次加密使用随机 nonce，确保相同明文产生不同密文

### 核心方法

```go
type CryptoService struct {
    key []byte
}

// 创建新的加密服务实例
func NewCryptoService(key []byte) *CryptoService

// 加密明文字符串
// 返回 Base64 编码的密文
func (c *CryptoService) Encrypt(plaintext string) (string, error)

// 解密密文字符串
// 参数为 Base64 编码的密文
func (c *CryptoService) Decrypt(ciphertext string) (string, error)
```

### 加密流程

```
1. 生成随机 nonce (12 字节)
   ↓
2. 使用 AES-256-GCM 加密明文
   ↓
3. 将 nonce 和密文分别进行 Base64 编码
   ↓
4. 拼接为 "nonce:ciphertext" 格式
   ↓
5. 返回加密结果
```

### 解密流程

```
1. 解析 "nonce:ciphertext" 格式
   ↓
2. 分别对 nonce 和密文进行 Base64 解码
   ↓
3. 使用 AES-256-GCM 解密
   ↓
4. 返回明文
```

### 安全特性

1. **密钥安全**:
   - 密钥存储在配置文件或环境变量
   - 密钥长度 256 位，符合高强度加密标准

2. **随机性**:
   - 每次加密使用随机 nonce
   - 相同明文产生不同密文，防止模式分析

3. **完整性**:
   - GCM 模式提供认证加密
   - 自动检测密文是否被篡改

### Go 实现要点

- 使用 `crypto/aes` 包
- 使用 `crypto/cipher` 包的 GCM 模式
- 使用 `crypto/rand` 生成随机 nonce
- 使用 `encoding/base64` 进行编码

## 🔄 类型映射器 (TypeMapper)

### 功能说明

类型映射器负责在 MySQL 和 Elasticsearch 之间进行数据类型转换。

### 核心方法

```go
type TypeMapper struct{}

// 将 MySQL 数据类型映射到 Elasticsearch 类型
func (tm *TypeMapper) MySQLToES(mysqlType string) string

// 将 Elasticsearch 数据类型映射到 MySQL 类型
func (tm *TypeMapper) ESToMySQL(esType string) string

// 将主键值映射为字符串（用于 ES 的 _id 字段）
func (tm *TypeMapper) MapPrimaryKey(pkValue interface{}) string
```

### MySQL → Elasticsearch 类型映射

| MySQL 类型 | ES 类型 | 说明 |
|-----------|---------|------|
| INT, BIGINT, SMALLINT, TINYINT, MEDIUMINT | long | 整数类型 |
| TINYINT(1) | boolean | 布尔值（特殊处理） |
| VARCHAR, CHAR, ENUM, SET | keyword | 短字符串 |
| TEXT, MEDIUMTEXT, LONGTEXT | text | 长文本 |
| DATETIME, TIMESTAMP, DATE | date | 日期时间 |
| TIME, YEAR | keyword | 时间类型 |
| BOOLEAN, BOOL | boolean | 布尔值 |
| FLOAT, DOUBLE, DECIMAL | double | 浮点数 |
| JSON | object | JSON 对象 |
| BLOB, BINARY | binary | 二进制数据 |
| GEOMETRY, POINT 等 | geo_shape | 空间类型 |
| 其他 | keyword | 默认类型 |

### Elasticsearch → MySQL 类型映射

| ES 类型 | MySQL 类型 | 说明 |
|---------|-----------|------|
| long, integer, short, byte | BIGINT | 整数类型 |
| text | TEXT | 长文本 |
| keyword | VARCHAR(255) | 短字符串 |
| date | DATETIME | 日期时间 |
| boolean | BOOLEAN | 布尔值 |
| double, float | DOUBLE | 浮点数 |
| object, nested | JSON | JSON 对象 |
| binary | BLOB | 二进制数据 |
| 其他 | VARCHAR(255) | 默认类型 |

### 特殊处理

1. **TINYINT(1) → boolean**:
   - MySQL 中 TINYINT(1) 通常用作布尔值
   - 自动识别并映射为 ES 的 boolean 类型

2. **带括号的类型**:
   - 自动提取基础类型: `VARCHAR(255)` → `VARCHAR`
   - 忽略长度和精度参数

3. **主键值转换**:
   - 字符串: 直接返回
   - 数字: 转换为字符串
   - 布尔值: 转换为 "true" 或 "false"
   - null: 返回空字符串

## 📝 进度日志系统 (TaskLogger)

### 功能说明

进度日志系统负责管理任务执行过程中的日志信息，支持实时推送到前端。

### 核心特性

- **内存缓存**: 每个任务保留最近 1000 条日志
- **实时推送**: 通过 SSE 推送到前端
- **日志分类**: 支持 4 种日志分类
- **日志级别**: 支持 Info, Warn, Error 三个级别

### 数据结构

```go
// 日志条目
type LogEntry struct {
    Timestamp string `json:"timestamp"` // 时间戳
    Level     string `json:"level"`     // 日志级别
    Category  string `json:"category"`  // 日志分类
    Message   string `json:"message"`   // 日志消息
}
```

### 核心方法

```go
type TaskLogger struct {
    taskLogs map[string][]LogEntry
    mu       sync.RWMutex
}

// 创建新的任务日志管理器
func NewTaskLogger() *TaskLogger

// 添加日志
func (tl *TaskLogger) AddLog(taskID, level, category, message string)

// 获取任务日志（从内存读取最近 1000 条）
func (tl *TaskLogger) GetLogs(taskID string) []LogEntry

// 清除任务日志（从内存中删除）
func (tl *TaskLogger) ClearLogs(taskID string)
```

### 日志限制

- 每个任务最多保留 **1000 条**日志
- 超过限制时，自动删除最早的日志
- 避免内存占用过大

## 🔧 响应封装工具

### 功能说明

统一封装 API 响应格式，简化控制器代码。

### 响应结构

```go
// 成功响应
type Response struct {
    Code    int         `json:"code"`
    Message string      `json:"message"`
    Data    interface{} `json:"data"`
}

// 分页响应
type PageResponse struct {
    Code     int         `json:"code"`
    Message  string      `json:"message"`
    Data     interface{} `json:"data"`
    Total    int64       `json:"total"`
    Page     int         `json:"page"`
    PageSize int         `json:"page_size"`
}
```

### 工具方法

```go
// 成功响应

func Error(c *gin.Context, code int, message string)

func PageSuccess(c *gin.Context, data interface{}, total int64, page, pageSize int)
```
